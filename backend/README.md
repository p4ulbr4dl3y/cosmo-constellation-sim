# Созвездие: ЦУП - Бэкенд

Сервис моделирования спутниковых группировок, динамической маршрутизации и оценки доступности связи в рамках второго кейса КосмоХакатона 2026.

## Стек технологий:
- среда выполнения: Python 3.13+;
- пакетный менеджер: `uv`;
- веб-сервер и интерфейс: FastAPI, Uvicorn;
- математические вычисления: NumPy;
- структуры данных и валидация: Pydantic;
- модульное тестирование и линтинг: Pytest, Coverage, Ruff.

## Быстрый старт

### Установка зависимостей
```bash
cd backend
uv sync
```

### Запуск сервиса
```bash
cd backend
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
Спецификация Swagger доступна по адресу:
`http://localhost:8000/docs`

### Запуск проверок качества кода
```bash
cd backend
uv run pytest
uv run ruff check
uv run ruff format --check
```

## Консольный интерфейс

Сервис включает консольную утилиту для автоматизированного расчета сценариев без запуска веб-интерфейса:

```bash
# Расчет всех эталонных сценариев из каталога data/
cd backend && uv run python -m app.cli --all

# Расчет выбранного сценария с выводом показателей доступности
cd backend && uv run python -m app.cli --scenario ../data/01_full_constellation.json

# Расчет сценария с сохранением результата в формате cosmo-A-result-1.0
cd backend && uv run python -m app.cli --scenario ../data/01_full_constellation.json --export ../result.json
```

## Методы программного интерфейса

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/health` | Проверка доступности сервиса |
| `GET` | `/api/presets` | Список эталонных сценариев из каталога `data/` |
| `GET` | `/api/presets/{name}` | Загрузка конфигурации сценария по идентификатору |
| `POST` | `/api/validate` | Валидация структуры `cosmo-A-1.0` с диагностикой ошибок на русском языке |
| `POST` | `/api/simulate` | Полный расчет горизонта 720 шагов, метрики доступности и причины разрывов связи |
| `POST` | `/api/snapshot` | Расчет единичного временного шага для визуализации |
| `POST` | `/api/export` | Экспорт результатов в формате `cosmo-A-result-1.0` |
| `POST` | `/api/compare` | Сравнение двух сценариев с расчетом дельты параметров и показателей качества |
| `POST` | `/api/recommendations` | Инженерные рекомендации по оптимизации группировки |
| `POST` | `/api/report/export` | Формирование и выгрузка аналитического отчета |

## Классификация отказов:
- `no_client_satellite`: отсутствие активного спутника над наземным клиентом;
- `gateway_offline`: отключение или техническое обслуживание всех наземных станций;
- `no_gateway_satellite`: отсутствие видимых космических аппаратов над шлюзами;
- `isl_disconnected`: отсутствие связного маршрута в межспутниковой сети при видимости терминалов.
