# Созвездие: ЦУП - Фронтенд

Веб-интерфейс пункта управления полетами для моделирования низкоорбитальной спутниковой группировки, маршрутизации и оценки доступности связи в рамках второго кейса КосмоХакатона 2026.

## Стек технологий:
- пользовательский интерфейс: React 19, TypeScript, Vite;
- стилизация и компоненты: Tailwind CSS, Lucide;
- графический рендеринг: Canvas 2D и Canvas 3D без сторонних 3D-библиотек;
- тестирование и линтинг: Vitest, Oxlint.

## Возможности интерфейса:
- интерактивная карта сети: двумерная эквидистантная проекция и трехмерный ортографический глобус, отображение 48 аппаратов, орбитальных плоскостей, зон радиовидимости, межспутниковых каналов связи и сквозных маршрутов;
- шкала времени и аналитика: управление суточным горизонтом 24 часа с шагом 120 с, скорости воспроизведения от 1x до 60x, диаграмма доступности по клиентам C65, C70, C72 с диагностикой причин разрыва;
- редактор конфигурации и стресс-тесты: переключение эталонных пресетов, загрузка сценариев `cosmo-A-1.0`, управление очередями развертывания и ручное отключение спутников на активном маршруте;
- аналитический модуль и сравнение: сопоставление сценариев A и B с расчетом дельты показателей качества, матрица рисков и выгрузка результатов в формате `cosmo-A-result-1.0`;
- автономный двухдвижковый режим: клиентское орбитальное ядро на TypeScript, полностью воспроизводящее расчеты бэкенда и обеспечивающее автономную работу без сервера.

## Команды разработки:

```bash
# Установка зависимостей
npm ci

# Запуск локального сервера разработки
npm run dev

# Проверка линтером
npm run lint

# Запуск модульных тестов
npm test

# Сборка оптимизированного комплекта файлов
npm run build

# Предварительный просмотр сборки
npm run preview
```
