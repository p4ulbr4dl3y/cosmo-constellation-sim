# Документация проекта «Cosmo Constellation Simulator» 📚

Центральный каталог документации, спецификаций и нормативных материалов (КосмоХакатон 2026, Кейс №2).

---

## 📑 Оглавление

### 1. Официальные спецификации хакатона
- **[01_постановка_задачи.md](01_постановка_задачи.md)** — Полная постановка задачи: параметры орбитальной группировки, физические ограничения (угол места $\ge 10^\circ$, дальность ISL до 3000 км), зоны видимости и требования к веб-сервису.
- **[02_описание_данных.md](02_описание_данных.md)** — Спецификация форматов входных сценариев (`cosmo-A-1.0`) и результатов моделирования (`cosmo-A-result-1.0`), структуры узлов, шлюзов, параметров и интервалов недоступности.
- **[03_критерии_оценки.md](03_критерии_оценки.md)** — Регламент и критерии оценивания решения (100 баллов):
  - *Раздел 1: Проектирование и анализ группировки* (до 35 баллов)
  - *Раздел 2: Веб-сервис и функциональность* (до 65 баллов)

### 2. Аналитические материалы команды
- **[RECOMMENDATIONS.md](RECOMMENDATIONS.md)** — Инженерный отчет по устойчивости группировки:
  - Архитектурное обоснование орбитального построения (48 КА, $h=550$ км, $i=87^\circ$).
  - Анализ динамики развертывания по 3 очередям запуска (SLA 18.56% $\to$ 98.10%).
  - Классификация уязвимостей (SPOF шлюза, деградация ISL при 2000 км, каскадные отказы 10 КА).
  - Обоснованные рекомендации по развитию наземного сегмента и межспутникового линка.
