# Документация проекта «Созвездие: ЦУП»

Центральный каталог документации, технических спецификаций, эталонных данных и аналитических отчетов.

---

## Разделы документации:

### 1. Нормативные спецификации:
- [01_постановка_задачи.md](01_постановка_задачи.md): регламентные требования, физические ограничения (угол места от 10 градусов, предельная дальность межспутниковой связи 3000 км), зоны видимости и целевые показатели качества;
- [02_описание_данных.md](02_описание_данных.md): форматы входных сценариев `cosmo-A-1.0` и результатов расчетов `cosmo-A-result-1.0`;
- [03_критерии_оценки.md](03_критерии_оценки.md): критерии оценки конкурсного решения (100 баллов).

### 2. Аналитические отчеты:
- [RECOMMENDATIONS.md](RECOMMENDATIONS.md): технико-экономическое обоснование проектных решений, расчет динамики очередей развертывания, классификация узких мест и системные рекомендации по развитию группировки.

### 3. Данные и референсный модуль:
- [data/](../data/): 4 эталонных сценария созвездия (`01_full_constellation.json`, `02_first_launch.json`, `03_satellite_outages.json`, `04_link_range.json`);
- [reference/geometry.py](../reference/geometry.py): эталонные функции аналитической геометрии, расчета координат ECI/ECEF и межспутниковых линий.

### 4. Первоисточники и медиа:
- [pdf/](pdf/): оригинальные регламентные документы от организаторов конкурса;
- [assets/](assets/): снимки экрана интерфейса и медиа (обновление: `npm run screenshots` в `frontend/`).
